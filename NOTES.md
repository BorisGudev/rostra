# Notes for whoever works on Rostra next

One entry per lesson. Newest at the bottom. Read this before changing anything.

- **The live site returns 401.** Netlify "site protection" (password or team login) is on for `luxury-toffee-412afa.netlify.app`. Nobody outside the team can open it. Turn it off in Netlify under Site configuration → Access & security before showing a school.
- **`src/*.js` share one global scope.** Files are concatenated in the order in `scripts/build.mjs`. A top-level `const` in `data.js` is visible everywhere. Top-level code may only use names from earlier files; component bodies may use anything. Prefix new globals (`Viva*`, `Gym*`, `Platform*`, `t*`) to avoid collisions.
- **Never load anything from a third-party host at runtime.** Fonts and React are copied from `node_modules` into `dist/` by the build. Loading from Google or a CDN sends every student's IP address abroad, which German courts have already fined (LG München 2022).
- **Netlify Functions stop at 60 seconds, streaming or not.** Keep every Claude call short enough to finish in 50 s: ask for compact JSON, use `effort: 'low'` or `'medium'`, and never chain two calls in one function.
- **The Anthropic key only ever lives in Netlify environment variables.** The browser talks to `/api/ai` with the user's Supabase session token. If you see `sk-ant` anywhere in `src/`, it is a bug.
- **Everything must run with no keys.** `MOCK_AI=1` (or simply no `ANTHROPIC_API_KEY`) makes `/api/ai` answer with realistic fixed JSON. The tests depend on this. If you add a new prompt, add a mock answer for it in `netlify/lib/mock.mjs`.
- **Do not add emotion words to prompts or UI.** The EU AI Act bans inferring emotions in schools. "Pace 142 words per minute" is fine; "you sounded nervous" is not. That is why confidence, expressiveness and the video presence read were removed.
- **The research notes in `.research/` were gathered from inside a sandbox with limited network.** Items marked `[S]` or UNVERIFIED were not read from the primary source. Check them before quoting prices or legal text to a school.
- **`npm test` needs no database.** `MOCK_SUPABASE=1` makes `scripts/dev.mjs` serve an in-memory Supabase (auth + tables + the RLS rules, approximated) at `/mock-supabase`; `MOCK_SEED=1` adds "Demo School" with teacher invite code `DEMOSCHOOL`. The browser uses the real `supabase-js` against it, so what passes here is what runs against Frankfurt. Row visibility in the mock is an approximation of `0001_init.sql`, not a copy: when you change a policy, change both.
- **Navigation is hash-based.** `go('page')` sets `#page`; the address bar never carries ids. A `page.goto('/#x')` in a Playwright test does not reload the page, it fires `hashchange`.
- **Students have no email.** Their login is `username@students.rostra.invalid`, created server-side with `email_confirm: true`, so Supabase never sends mail and its SMTP limits never matter. Password resets go through the teacher (Class page → Reset password).
- **Sign-out wipes the browser.** `Store.signOutLocal()` clears every cached document, because the next student on a classroom laptop must not see the last one's work.
- **Every interface string goes through `t()`.** English is the key; `rostra/src/i18n-bg.js` holds Bulgarian. `node scripts/i18n-extract.mjs --check` lists what has no translation. Changing the language reloads the page on purpose: top-level tables (exam formats, badges, lessons) are built once at load. Content in `data.js` (lessons, library speeches, quizzes) is English; the AI answers in the student's language because `/api/ai` adds that instruction.
- **Prompts stay English.** They are not wrapped in `t()`; the language line is added server-side (`LANG_LINE` in `netlify/functions/ai.mjs`). Translating prompts would change grading behaviour and the mock matching.
- **Node 22 is required.** `@supabase/supabase-js` 2.119 needs the runtime's own WebSocket, which Node 20 lacks. Netlify runs the functions on the build's Node version, so `.nvmrc`, `netlify.toml` and the CI workflow all say 22. Netlify's `netlify.toml` does not accept a `region` key under `[functions]`; the region is a dashboard setting (SETUP.md step 1).
