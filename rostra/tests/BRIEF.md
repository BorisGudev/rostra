
# ROSTRA — shared brief for every builder (read fully before coding)

## The product
Rostra is a gamified public-speaking coach that ships as ONE self-contained HTML page (a Claude "Artifact"). Users analyze speeches on Aristotle's three appeals (ethos, pathos, logos), prepare speeches with a coach that never writes the speech for them, take oral exams, train in a gym, learn rhetoric, earn XP/levels/badges/streaks. The user's verdict on v1: "I like it, but it looks pretty basic. Show your full artistic potential and go beyond." Your work must feel crafted, theatrical and alive, not template-y. Every module needs at least one SIGNATURE MOMENT: a visual or interactive beat people remember.

## Code layout (project root: rostra/)
- src/*.js are plain scripts concatenated into ONE global scope in this order: data.js, engine.js, ui.js, kit.js, art.js, pages-core.js, pages-more.js, viva.js, gym.js, app.js. No modules, no imports. Top-level names are globals; prefix new globals with your module name to avoid collisions (e.g. VIVA_*, Viva*, Gym*, GYM_*, art*). Top-level code may only reference names defined in EARLIER files; component bodies run later, so they can reference anything.
- src/*.css concatenated in order: styles.css, kit.css, art.css, viva.css, gym.css. Prefix your classes (viva-, gym-, art-...).
- Build: cd rostra && python3 build.py   (writes rostra.html)
- Tests (headless, JavaScriptCore): cd rostra && /System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc tests/harness.js -- "$PWD/src" "$PWD/tests/core.test.js" "$PWD/tests/<yours>.test.js"
  The harness stubs React and the DOM: html`` returns {strings, vals}, hooks return their initial values, effects never run. Calling a component function directly evaluates its whole render body, which catches ReferenceErrors/TypeErrors. Write tests/<yours>.test.js using the global check(name, fn) helper: call every component you write with realistic props in every state (empty, loading, populated, error), and unit-test pure logic (scoring, parsing, generators). Both core.test.js and yours must print ALL PASSED. Never put browser-only APIs (canvas, ResizeObserver, AudioContext, speechSynthesis, IntersectionObserver) in render bodies or top-level code; use them only inside effects/handlers and feature-detect them.
- Other builders are editing OTHER files at the same time. Only edit the files you own (listed in your task). If a test failure comes from a file you don't own, wait a minute and re-run; never edit it. Do not run git. Do not publish anything.

## Stack and htm gotchas
React 18 UMD + htm (`html` tagged templates, already bound). Use className, htmlFor, tabIndex, camelCase SVG attributes (strokeWidth, strokeLinecap, textAnchor, stopColor via style). htm does NOT decode HTML entities: write real characters (’ — · …). Keep text and ${...} on one line (htm trims whitespace containing newlines, which eats spaces). Components: <${Comp} prop=${x} /> and close with <//>. Keys on mapped lists. Hooks before any early return. For highlightable inline text use <span role="button" tabIndex="0">, not <button>. SVG fills/strokes that use CSS variables go in style={{fill:'var(--x)'}}, not attributes. CSS custom properties in style objects are fine ({'--c': 'var(--ethos)'}).

## Platform constraints (the artifact sandbox; violations silently break)
- No network: no fetch, no external images/media/fonts beyond what's loaded. Generate visuals with SVG/canvas. Fonts available: "Bricolage Grotesque" (all modern text, opsz/wght variable) and "GFS Didot" (Greek and quotations). Two voices only.
- No microphone or camera. No alert/confirm/prompt (build confirmations into the UI). No window.print. No window.open (use <a href target="_blank">).
- File downloads: offerDownload(filename, text) for text/markdown. For images: const dl = await window.claude?.use?.('downloads'); await dl.save({filename:'x.png', data: blob}) inside a click handler, handle rejection (code 'declined' = do nothing) and null (unavailable: tell the user).
- Text-to-speech (speechSynthesis) may or may not exist: use the kit's Voice helper, which feature-detects.
- Must work at 375px width with no horizontal scroll; 16px side gutters come from the shell. Respect prefers-reduced-motion (reducedMotion() helper; CSS media query already kills animations globally). Visible keyboard focus. Every color from tokens so light and dark themes both work (the .stage set piece is deliberately dark in both).
- AI: the page calls Claude through AI.json(prompt, opts) and AI.text(turns, opts) (wrappers over window.claude sample capability). Calls spend the viewer's usage, so only call on explicit user action, never in loops/timers. opts: {signal, modelTier:'quick'|'default'|'complex', cache:false for anything that must vary, onText:({text})=>{} to stream}. AI.json resolves parsed JSON (validate every field; never trust shape). Errors reject {code}; show aiErrorText(e) via toast(…,'bad') or inline. Store.state.ai is 'checking'|'ready'|'off'; when 'off', features must still work with a good offline fallback (static banks, self-assessment).

## Art direction: "The Stoa"
- Concept: a stoa at dusk. Ethos, pathos and logos are three lights, blue, red and green, that fall hard-edged between columns onto stone. Each light is as bright as its score. The triangle stands in them.
- Two voices: the modern word is bold (Bricolage Grotesque), the Greek one whispers beside it (GFS Didot italic). Add Greek as a quiet companion to an English word, never instead of it, and only real words.
- Self-annotating copy: key lines use a real figure of speech and name it in the margin with Scholion (a FIGURES key, plus the words that carry it in mark). Never tag a line with a figure it does not use.
- Surfaces: warm stone by day, night sky by night, flat with hairlines. The .stage set piece stays dark in both themes. Corners stay small.
- Colour has one meaning each: gold is what you press and what you earn; blue, red and green are the three appeals and nothing else.
- Ornament with meaning, sparingly, one Greek gesture per screen: meander for progress and friezes, laurels for rank, the klepsydra for time, columns and pediments for structure.
- No glows, blur, soft cones or gradient washes. Light has edges. Motion: one orchestrated moment per screen, and every screen is complete and readable on first paint.
- Sound: soft synthesized chimes; applause for great results; nothing loud; always optional.
- Avoid generic AI looks: no emoji as icons, no identical rounded cards everywhere, no "everything centered".
- Copy: plain, warm, direct, second person, active voice. Specific over clever. No em-dash asides, no "not X, but Y", no scare quotes, no filler like "worth noting". Buttons say exactly what happens.
